# Character Images

Place transparent PNG images in this directory to display them in the bottom right corner of the site.

## Usage

Images placed here will be accessible at `/images/filename.png` and can be displayed on any page.

## Recommended Specifications

- **Format**: PNG with transparent background
- **Size**: 300-500px width recommended
- **Position**: Will appear in bottom right corner, fixed position

## Example

To add a character image:
1. Place your PNG file in this directory (e.g., `character.png`)
2. The image will automatically be available at `/images/character.png`
